# SteelEye 钢铁表面缺陷智能检测系统 — 用户操作手册

本手册旨在帮助现场质检员、车间主管、工艺工程师和系统管理员快速熟悉并掌握 **SteelEye 钢铁表面缺陷智能检测系统（v4.2.0-Pro）** 的日常操作与维护。

---

## 一、 系统角色划分与权限定义

系统基于权限隔离原则，提供 5 种业务角色。默认测试账户为：
* **账号**：`admin`
* **密码**：`123456`
* *(实际现场使用中，由系统管理员根据岗位分配专用子账号)*

| 角色 | 核心工作场景 | 主要操作权限 |
| :--- | :--- | :--- |
| 🧑‍✈️ **现场质检员** (`inspector`) | 产线一线质检现场监控 | 1. 实时检测监控、切换视图模式<br>2. 对存疑 AI 结果进行修正确权并保存<br>3. 调用 RAG 根因辅助分析与 AI 悬浮助手 |
| 🕵️‍♂️ **质检主管** (`supervisor`) | 质量监控与报表统计 | 1. 访问全局质量 KPI 仪表盘（漏检/过杀率等）<br>2. 多条件筛选检索检测历史数据<br>3. 导出 CSV/HTML 可视化质检报告 |

## 二、 核心功能模块操作指南

### 1. 用户认证与登录
1. 双击桌面快捷方式或在浏览器输入系统服务地址（本地部署默认：`http://localhost:8000`）。
2. 进入深色极简登录界面，输入用户名和密码。
3. 点击 **登录**，系统自动根据用户角色跳转至对应的操作工作台。
4. 如需切换账号，点击顶部右侧的 **登出** 按钮即可清除会话并返回登录页。

### 2. 产线实时智能检测看板 (质检员/主管)
* **模式选择与图片输入**：
  * **模拟模式**：在控制区点击“Preset 缺陷标样库”，可选择“裂纹 (Crazing)”、“夹杂 (Inclusion)”等典型缺陷图片进行模拟检测。
  * **实时相机**：开启“工业相机采集模式”，系统将自动从 RTSP 流（或生产监控共享目录）中周期性捕获图片。
  * **本地上传**：支持直接将外部图片拖拽至检测框，或点击框体选择本地文件。
* **激光扫描与结果可视化**：
  * 点击 **开始检测**，系统将启动科技感“激光扫描动效”，并在 50ms 内（YOLO 通路）完成推理。
  * 图像区将渲染带彩色缺陷包围盒的标注图，且包围盒上带有对应的缺陷英文缩写（如 `CRACK` 表示裂纹，`SCALE` 表示氧化皮）。
* **多视图切换**：
  * 系统提供四种画面强化通道，质检员可根据实际情况点击按钮切换：
    * **真彩镜面**：展示工业相机原始真彩图像。
    * **红外应力**：模拟板材受力红外光谱，辅助观察形变。
    * **边缘提取**：采用 Canny 算子高亮缺陷轮廓，方便观察细微划痕。
    * **偏光强化**：极度拉伸明暗对比度，使锈斑、麻点更易分辨。
* **缺陷热力图**：
  * 勾选“显示缺陷密度热力图”，系统将在图像上动态叠加缺陷分布的二维高斯热力场，缺陷越密集的位置红黄色越深。

### 3. 严重度分级与 RAG 根因分析 (人机协同核心)
检测完成后，屏幕右侧的“一体化滚动分析面板”会呈现以下内容：
* **自动缺陷卡片**：展示缺陷 ID、类别、置信度、长宽以及系统根据公式（*面积占比 60% + 置信度 40%*）自动评定的严重度等级：
  * **A 级 (严重)**：红色高亮，多为大面积裂纹或深划痕，系统自动标记“建议立即停机”。
  * **B 级 (中等)**：橙色高亮，需要下道工序注意。
  * **C 级 (轻微)**：黄色高亮，属于合格范围内斑点。
  * **D 级 (忽略)**：蓝色，细微噪点，可忽略。
* **RAG 冶金根因与处置意见**：
  * 系统利用 RAG 技术在缺陷卡片下侧吐出深度分析：“该缺陷类型为**氧化皮**，根因推测为：*板坯加热温度过高或在炉时间过长，致使生成一次氧化铁皮...*；改进建议：*调整 2 号除鳞集管喷嘴水压，确认冷却速率。*”

### 4. 人工审核确权与 Bad Case 管理 (质检员/工程师)
若质检员发现 AI 判定的类型存在偏差，或有漏检/过杀情况，可直接发起审核：
1. 点击缺陷卡片旁的 **修正** 按钮，在弹出的窗口中修改缺陷类别、重新划定严重度，并输入备注。
2. 提交保存后，此条记录的数据库状态将由 `unreviewed` 更新为 `corrected`。
3. 置信度低于 `0.5` 的样本会被系统自动标记为 **Bad Case**，统一归集至 Bad Case 面板中，标记为“待人工复核”，供 AI 工程师进行下一步的模型重训迭代。

### 5. 数据飞轮一键重训 (AI工程师)
1. 切换至 `ai_engineer` 角色，进入 **数据飞轮与模型迭代** 控制面板。
2. 面板上会实时显示“当前待重训的 Bad Case 样本数量”。
3. 确认数量充足后，点击 **开始增量重训** 按钮。
4. 系统将在后台启动 YOLO 重训子进程，前端控制面板将实时刷新：
   * **训练进度条**：显示当前的 Epoch 步数（例如 3/50 Epoch）。
   * **动态图表**：实时渲染 Loss 下降曲线与 mAP 准确率提升曲线。
5. 训练完毕后，新模型权重将平滑自动加载应用，无需重启服务器。

### 6. 数据报表导出 (主管/工艺工程师)
在历史记录或数据大屏下方，提供一键导出工具：
* **导出 CSV 报表**：一键导出包含检测时间、缺陷类型、严重度分布、耗时、审核状态及备注的结构化表格。
* **生成 HTML 报告**：生成一份带有饼图、柱状趋势图及标注缩略图的独立可视化质量分析报告网页，可直接打印。

### 7. AI 工艺助理 (悬浮对话)
在系统大屏右下角，提供“AI 工艺助理”悬浮框。
* 点击展开，在对话框中输入如：“*氧化皮与夹杂有什么区别？*”或“*帮我查下今天上午被标记为 A 级缺陷的板材记录*”。
* 工艺助理会自动联动后台 RAG 知识库与本地数据库，给出专业的冶金工艺答复。

## 三、 常见问题解答与故障排查 (FAQ)

#### Q1: 输入用户名和密码后，提示“登录认证失败”？
* **排查**：请确认输入了正确的用户名（如 `admin`）和密码（默认 `123456`）。若仍失败，请联系系统管理员在数据库中查询或重置对应用户的 `password` 哈希字段。

#### Q2: 实时检测时，界面提示“VLM API 连接超时，已自动降级为 LocalAnalyzer”？
* **排查**：这说明工控机访问阿里云百炼或云端 API 出现网络波动或超时（超过了 `config.yaml` 中配置的 8.0 秒限制）。
* **说明**：系统此时已自动触发降级保护，使用本地 OpenCV 边缘检测与灰度统计分析兜底，确保产线检测不中断，历史记录仍会正常归集。请检查工控机网线或边缘网关的联网策略。

#### Q3: 启动后台重训时，感觉实时检测响应变慢了？
* **说明**：系统检测到后台重训运行时，为保障工控机显存不发生 OOM 崩溃，会自动将当前的实时检测推理临时降级为 CPU 运算。此时实时单张延迟可能从 10ms 升至 40~90ms（具体取决于 CPU 性能，本次测试 `yolo26n.pt` 在 CPU 上运行仅需约 42ms），此为系统的资源保护性机制。训练完成后会自动恢复为 GPU 模式。
